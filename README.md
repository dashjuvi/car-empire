# Garage Rush

Free, ad-free idle car tycoon + driving web game.

**Play:** https://dashjuvi.github.io/car-empire/

Single-file vanilla JS game. Collect luxury cars (Porsche, Ferrari, Lamborghini, Aston Martin, Bugatti, Tesla, McLaren), drive stages from Local Streets to the Multiverse, prestige, and speedrun.

No ads, no tracking, no IAP. Offline-friendly. Add to Home Screen on iPhone.
